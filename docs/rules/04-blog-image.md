# 丸伊不動産｜相続ブログ アイキャッチ画像ルール

## 1. 目的

将来、記事本文が完成した後に、アイキャッチ画像を自動生成してMarkdownのfrontmatterへ設定するための基準を定義する。

人間が毎回Canva等で画像を制作しなくても、ブログ全体で一定の品質・統一感を維持できる状態を目標とする。

想定する流れ：

記事テーマ → 記事本文 → 記事内容に合ったアイキャッチ画像生成 → 画像保存 → Markdown frontmatterの`image:`へ設定

このファイルはルール定義のみであり、画像生成APIの実装・画像ファイルの自動生成処理そのものはこのファイルでは行わない。

## 2. 基本仕様

* 比率：16:9
* 基本サイズ：1200 × 675px
* 保存先：`public/blog/images/`
* ファイル形式：原則 `.jpg`
* ファイル名：記事slugと同一
* 例：`public/blog/images/okinawa-souzoku-jikka-korekara.jpg`

Markdown frontmatterでは、以下の形式で指定する。

```
image: "/blog/images/{slug}.jpg"
```

## 3. デザインの基本方針

`01-company-brand.md` のブランド方針と一致させる。

基本イメージ：

* 落ち着いている
* 清潔感がある
* 明るい
* 誠実
* 安心感がある
* 沖縄らしさを自然に感じられる
* 40〜70代でも見やすい
* 過度に広告っぽくしない

記事ごとに画風・テイストを大きく変えず、ブログ全体で統一感を持たせる。

## 4. 沖縄らしさの扱い

必要に応じて、以下を使用してよい。

* 沖縄の住宅
* 赤瓦
* 福木
* 土地
* 街並み
* 海や空
* 緑
* 沖縄らしい自然光

「沖縄らしさ」を出すためだけに、青い海・南国植物・派手な観光写真を毎回入れる必要はない。

記事テーマとの関連性を、沖縄らしさより優先する。

## 5. 記事内容との関連づけ

画像は記事タイトルだけで機械的に決定せず、記事本文の主題を確認したうえで決定する。

例：

* 実家の相続 → 沖縄の住宅、家、庭、住宅街など
* 土地の相続 → 土地、住宅地、空き地、周辺環境など
* 家族で考えるテーマ → 家・家族を連想させる穏やかな場面
* 売却・活用 → 不動産や土地の選択肢を連想させる場面
* 軍用地 → 軍用地を過度に強調せず、記事内容上必要な場合のみ慎重に表現する

## 6. 軍用地の扱い

`02-souzoku-lp.md` の軍用地に関する方針と一致させる。

軍用地を相続ブログ全体の主役にはしない。

軍用地関連の記事であっても、以下は避ける。

* 米軍基地を強烈に見せる
* 軍用機を主役にする
* フェンスや軍事施設を過度に強調する
* 戦争・軍事を連想させる刺激的な表現

記事内容上必要な場合のみ、沖縄の土地・地域性の一部として控えめに扱う。

## 7. 人物表現

人物を使用する場合は、以下を基本とする。

* 自然な表情
* 穏やかな雰囲気
* 年齢層を極端に若くしない
* 大げさな演技をさせない

禁止例：

* 頭を抱えて絶望している
* 泣いている
* 強い不安を表現している
* お金を大量に見せる
* 驚きすぎた表情
* 「今すぐ売らないと危険」と感じさせる表現

## 8. 禁止する画像表現

以下は禁止する。

* 恐怖を煽る
* 不安を過剰に刺激する
* 緊急性を演出する
* 損失を強く連想させる
* 家族トラブルを煽る
* 遺産争いをセンセーショナルに描く
* 現金・札束を強調する
* 法律・税務の専門家と誤認させる表現
* 実在する特定人物に見える人物生成
* 他社ロゴ
* 著作権上問題のあるキャラクター
* 他社広告の模倣
* 不動産価値や節税効果を保証しているような表現

これは `01-company-brand.md` の「禁止するコミュニケーション」および `03-article-workflow.md` の「煽り表現の禁止」と同じ考え方を、画像表現にも適用するものである。

## 9. 画像内の文字

アイキャッチ画像そのものには、原則として文字を入れない。

理由：

* 記事タイトルはWeb側（`/blog`、`/blog/[slug]`、LPのArticleTeaser）で別途表示される
* スマートフォンで文字が潰れる
* 自動生成時に文字が崩れるリスクを避ける
* 同じ画像を `/blog`、`/blog/[slug]`、LPのArticleTeaserで使い回しやすくする

画像は「記事内容を視覚的に補助するもの」とし、情報を画像内の文字で伝えようとしない。

## 10. ニューロマーケティングの扱い

`02-souzoku-lp.md` のニューロマーケティング方針と一致させる。

画像においては、以下の方向でのみ使用する。

* 視線誘導
* 安心感
* 情報処理のしやすさ
* 親近感
* 選択肢を整理しやすい視覚表現

以下は禁止する。

* 恐怖訴求
* 損失回避を過度に刺激する表現
* FOMO（今しかない、という煽り）
* 強制的な緊急性の演出
* ダークパターン
* 誤認を利用した誘導

## 11. 自動生成時の判断優先順位

将来の自動画像生成では、以下の優先順位で画像内容を判断する。

1. 記事本文との関連性
2. 丸伊不動産のブランド方針（`01-company-brand.md`）
3. 読者への安心感・分かりやすさ
4. ブログ全体の統一感
5. 沖縄らしさ
6. 見栄え

「映える画像」を作ることより、記事内容との整合性を優先する。

## 12. 将来の自動化フロー（想定・未実装）

将来的には、以下の流れを想定する。

記事生成 → 記事内容の安全チェック → 画像生成内容の決定 → アイキャッチ画像生成 → `public/blog/images/{slug}.jpg` へ保存 → Markdown frontmatterの`image:`へ設定 → 公開

このファイルはルール定義のみであり、上記フローの実装（画像生成APIとの連携、自動保存処理、自動frontmatter設定処理等）はこのファイルでは行わない。実装は別工程で人間と相談のうえ進める。

## 13. 人間による確認

`03-article-workflow.md` の「記事の下書き状態」「人間による確認」「公開承認」の方針と同様に、自動生成されたアイキャッチ画像についても、本番公開前に人間が内容を確認できる状態を維持する。

画像単体の生成・保存をもって、自動公開の承認としない。

## 14. このルールの優先順位

このファイルは、`01-company-brand.md`・`02-souzoku-lp.md`・`03-article-workflow.md` の内容と矛盾しない範囲でのみ適用する。

矛盾する内容が生じた場合は、勝手に判断せず人間へ確認する。
